# 探索活动助手 · 使用说明

一个纯前端、可离线使用的探索活动规划工具：多资源、多工厂、多升级，算出先买什么、什么时候点升级，并在到点时提醒。

构建后只有一个 `dist/index.html`，双击即可使用，不需要服务器。算法细节见 [算法与策略](算法与策略.md)。

## 快速开始

1. 在 **① 资源** 里添加资源：选一个预设 emoji，填当前数量、基础产出和总计产出。资源没有名称，只靠图标区分。右上角可选择 **全局广告倍率 ×1/×2/×4**，它乘在所有工厂产出上，工厂输入的是**不含该倍率的基准单台产出**。
   - 总计产出 = 基础产出 + 有效工厂贡献（已乘升级倍率和全局广告倍率）；
   - 输入基础产出会自动算出总计；直接修改总计会反推出基础产出（总计减去工厂贡献）。
2. 在 **② 升级** 里填目标工厂、产出倍率、升级价格（右侧图标是花费资源）；买下后目标工厂的产出会乘以该倍率。未满足前置条件的升级会锁定，可勾选 **隐藏未解锁** 过滤掉，开关会持久保存。
3. 在 **③ 工厂** 里填每个工厂（单行四项）：
   - 标题行显示工厂序号、快速结算、当前贡献和删除；已拥有数量为 0 的工厂自动视为新工厂；
   - 已拥有数量、下一台价格、单台产出/秒、价格增长倍率（留空用全局倍率）；
   - 价格输入右侧的图标是价格资源，产出输入右侧的图标是产出资源（可以不同）；
   - 数据不完整/无效的工厂会自动灰显并忽略：不参与产出和规划，快速结算按钮也不可用。
4. **④ 最优方案** 会给出下一步、完成时刻和时间表；可切换「在线最快 / 离线攒钱」策略，也可点「提醒我」或「逐步执行」。

## 预设导入

在右下角 **⚙️ 悬浮球菜单 → 📥 引入预设…** 里选择预设。

### 微型探索 · 面对恐惧

- 预设文档数值以**声望 2**为基准；导入时可输入当前声望等级和徽章加成。
- 文档产出包含 **全局广告 ×4**：导入时先除以 4 存成基准单台产出，再按声望和徽章换算；请在页面顶部选择你实际的全局广告倍率。
- 声望：每升一级，收入 ×2、成本 ×4（从声望 1 起累乘）。
- 徽章：只增加收入，以 5% 为单位，例如 +10% 表示收入再乘 1.1。
- 导入会**重置**当前资源、工厂、单台产出、升级、计划和提醒，不能撤销。
- 工厂默认从 0 台开始，请按游戏实际已拥有数量填写。
- 面对恐惧的三个工厂成本增长倍率固定为 **1.15**。
- 文档里的“解锁条件”会转成前置条件：未满足时显示锁定、不能购买，规划器也不会把它排进时间表。
- 当前实现暂不参与规划：篝火的「点击收益 +1」。

### 生命解剖学

- 两种资源：🔵 脱氧血液、🔴 带氧血液；工厂可以消耗一种资源、产出另一种资源。
- 文档数值以**声望 1**为基准：成本不额外缩放，进入更高声望时成本 ×4/级、收入 ×2/级。
- 文档产出包含全局广告 ×4；导入时先除以 4，再按声望/徽章换算，页面顶部仍可另选全局广告倍率。
- 「内分泌系统」至少 5 台才能解锁「骨骼」，该数量条件已经支持。
- 点击收益升级「血液」「静脉」暂未纳入规划，因此「心脏」的解锁条件暂未建模；其余工厂/升级前置已转换。
- 文档尚未填写完整；后续补充数据时继续扩充 `src/data/presets.ts`。

## 资源与产出

所有资源共用同一张规划表。工厂的当前贡献为：

```text
工厂贡献 = 已拥有数量 × 单台产出 × 升级倍率 × 全局广告倍率
资源总产出 = 基础产出 + 该资源下所有工厂贡献之和
```

单台产出和升级倍率都按基准值保存；全局广告倍率是顶部的独立选项，改变它会立即重算产出和计划。

购买升级时会直接把倍率乘进目标工厂的「单台产出」，没有隐藏乘数；填错了直接改单台产出即可。

## 工厂、升级与新工厂

- **快速结算**「买1/5/10个」：扣除连续购买的总价（价格按增长倍率递增），增加已拥有数量，更新下一台价格。
- **未解锁工厂**：拥有数量不可直接编辑，普通点「买X个」也不会购买；按住 Ctrl 点「买X个」可强制购买并解锁（资源不足时清零）。
- **按住 Ctrl 强制购买**：点「买X个」时如果资源不足，仍会增加工厂并把支付资源清零；按住 Ctrl 期间这些按钮会变色提示。
- **购买升级**：扣除对应资源，把倍率直接乘到目标工厂的单台产出，然后从列表删除升级；工厂贡献立即更新。按住 Ctrl 点购买可在资源不足时强制购买，并把支付资源清零。
- **删除升级**：只移除未购买的升级，不扣资源、不应用倍率。
- **新工厂**：已拥有数量为 0 的工厂自动视为新工厂，规划目标会优先变成“最快点出第一个新工厂的首台”。买到首台后它不再是新工厂，对应升级解锁，目标切回“完成全部升级”。如果所有 0 台工厂都被前置条件锁住，规划会先回退到“完成升级”，用升级链解锁工厂，再在重新规划时切回新工厂。追求新工厂首台时，搜索仍可顺路购买已解锁升级——只要升级带来的产出提升能缩短攒钱时间。
- 新工厂还没买首台时，指向它的升级不能购买，按钮会显示“需先买目标工厂首台”。

## 数字显示格式

右下角 **⚙️ 悬浮球菜单** 提供数字显示格式下拉、预设导入和倍率助手：

- **英文后缀**：`1.23K / 1.23M / 1.23B / 1.23T / 1.23Qa…`
- **中文单位**：`1.23万 / 1.23亿 / 1.23兆 / 1.23京…`
- **科学计数法**：`1.23e12 / 2.33e14`

带单位时保留 3 位有效数字；超出范围自动用科学计数法。切换会转换所有资源的数量、基础产出、工厂价格/产出和升级价格；已拥有数量、倍率不转换。设置保存在 `cts_notation`。

## 快捷操作与键盘

- 工厂快速结算、删除、拖动手柄都不进入 Tab 顺序；正常填写不会被它们打断。
- 资源图标下拉、全局/工厂增长倍率、升级倍率和离线收益倍率也不进入 Tab 顺序，用鼠标点选即可。
- 拖动手柄可调整工厂顺序，顺序变化会保存并重新规划。
- 「逐步执行」中每点一次「完成此步」会把该步的购买应用到当前数据（扣资源、加拥有数或买升级），然后推进到下一步。
- 手动用「买X个」或「购买」也会记录到数据并自动重算。数据编辑和计划外购买统一走 **300ms 防抖**：旧计划先作废，300ms 内的连续操作合并成一次重算。
- 资源总量输入是权威快照：重算直接使用你输入的数量，不叠加防抖等待期间自动增长的产出。
- 数据输入框保持焦点时，计划重算会等待 900ms 再启动。
- 快速购买只更新对应行和资源数量，不再整块重建编辑器。

## 提醒

- 点「提醒我」= 以当前数据为快照，开始为下一步倒计时；刷新或重新打开页面后倒计时继续。
- 离线收入广告翻倍：启用后整段离线收入 ×2；离线方案的计划时间、以及在线/离线方案的提醒等待都会按 2× 缩短。
- 到点提醒 = 页面横幅 + 蜂鸣 + 标题闪烁；若浏览器通知已授权，还会弹系统通知。
- 右上角「提醒」抽屉可暂停、恢复、重新计时或取消当前规划的提醒。

## 数据与迁移

- 当前存档键：`cts_data_v6`；资源（含 emoji）、工厂、升级、计划和提醒都在里面。
- 旧版 v5 的多个分类会合并成一个数据集：分类变成资源，分类 emoji 变成资源 emoji，工厂/升级引用会重映射；旧的分类级计划/提醒不再适用，需要重新规划。
- 旧版 v4/v3 的固定三个槽位本来就是不同资源：每个非空槽位迁移成一个资源，原工厂跟随该资源，原来的单一升级迁移为目标为该资源第一个工厂、倍率 1 的升级；活动槽位的提醒会保留。
- 旧版 v2 的单组数据迁移成一个资源。
- 设置键：`cts_volume`、`cts_half`、`cts_notation`、`cts_offline_rate`、`cts_global_ad`。

## 性能

规划计算在浏览器中通过内联 Web Worker 执行，构建仍是单文件。规划耗时不会阻塞输入；没有 Worker 的环境会退回同步计算。
