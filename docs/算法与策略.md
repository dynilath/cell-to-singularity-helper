# 算法与策略

本文记录助手的规划目标、批量投资搜索和离线等待规则。使用说明见 [使用说明](使用说明.md)。

## 唯一策略：有界分段规划

界面不区分「在线最快 / 离线攒钱」。每次规划执行：

```text
选一个当前分段目标
→ 建立无投资直接计划作为保底
→ 用批量宏和多步补全寻找投资组合
→ 在固定预算内用 Beam Search 改进
→ 精确重放成逐步可执行计划
```

一个计划只显示“当前段”，买完后重新选目标、重新搜索，不生成未来全部长链。搜索是有界启发式规划，不承诺全局最优。

## 目标选择

### 有锁定项时

从所有锁定工厂/升级反向遍历前置，收集“已经可以执行、只差购买”的前置节点：

- 升级 → 目标为购买该升级；
- 工厂首台 → 目标为买出首台；
- 工厂数量门槛 → 目标为补到所需数量。

多个候选时选预计等待最短的一个。搜索期间固定该目标，只优化到达目标前的投资组合。

### 没有锁定项时

在该状态下选择一个可执行的新工厂或未购买升级；所有工厂至少 1 台且升级全部买完后，规划完成。

## 统一模拟与批量宏

`src/core/plannerSimulation.ts` 是在线等待、离线推进、购买、升级和宏重放的唯一结算实现。直接计划、贪心补全、Beam 和最终输出共用这套逻辑。

工厂动作使用 `buy-k` 宏压缩搜索深度，但宏内部仍然逐台结算：

```text
等待下一台可购买
→ 买一台
→ 更新数量、下一台价格和资源产出
→ 重复直到买满 k 台
```

因此不能用“按初始产出攒完整批总价再一次购买”代替宏模拟；先买的工厂必须参与后续等待的产出。

候选批量包含：

- 1 台和 2 的幂档位；
- 当前存量立即可负担的最大数量及其下一档；
- 距离工厂数量门禁还缺的台数。

搜索节点只保存宏和父路径。最终选中方案后才展开成逐台 `PlanStep`，界面和 Worker 协议不变。

## 相关动作图

当前分段使用静态相关图收集动作，包含：

1. 目标的成本资源及生产这些资源的工厂；
2. 能放大已纳入工厂的升级；
3. 新工厂/升级的成本资源；
4. 工厂和升级的前置解锁边。

求不动点时不使用固定 8 层截断，也不会因为节点暂时锁定就永久排除。动作展开时再检查动态前置。相关图只保证覆盖，搜索仍用动态候选数量限制控制分支。

## 保底、补全与 Beam

先生成在线/离线的无投资目标计划，作为 anytime 保底。之后不再分别执行 direct/full 两遍搜索，而是在同一相关图中评估动作。

多步贪心补全用于发现延迟收益：

```text
强制先买一个候选工厂
→ 从购买后的状态继续补全投资、升级和目标
→ 比较完整分段时间
```

因此肾脏即使让目标红色资源暂时减少，也能通过“肾脏 → 左心室 → 肝脏”的完整结果被保留。单步立即收益不再是从搜索中删除动作的硬性条件。

Beam 每层保留固定宽度的状态，并给不同末动作保留代表，避免直接生产者的微小变体占满宽度。每次得到更短完整路径就更新保底；预算耗尽时返回最近一次完整方案。

同一配置下，只有“时间不更晚且每种资源都更多”的状态才能支配另一状态。每个配置只保留少量 Pareto 项，并保留时间极值和资源极值；前沿只保存时间和资源量，不保存完整状态副本。

## 下界与微小收益

搜索使用乐观产出构造剩余时间下界：假设相关升级免费获得、工厂达到规划数量上限，并忽略购买时间、前置和离线取整：

```text
h = 目标剩余资源缺口 ÷（最大可能产出 × 最大等待倍率）
```

该下界只用于安全剪枝，不用于证明启发式候选覆盖之外的最优性。贪心补全得到的是可行方案上界，只用于排序和更新保底。

最终投资计划与同一初始状态的无投资直接计划比较。整段改善不足 `max(5 秒，直接基线的 0.5%)` 时返回直接计划，避免反复推荐微小收益。该门槛不作用于单个投资动作。

## 在线等待与 3 分钟离线块

每次等待都支持两种模式：

```text
在线等待 = 还差资源 ÷ 在线产出
离线原始时间 = 还差资源 ÷（在线产出 × 离线收益倍率）
离线等待 = 向上取整到 180 秒的整数倍
```

离线等待只使用完整的 `180 / 360 / 540 …` 秒块，溢出资源保留。离线宏每次回来后连续买下当前可负担的计划内工厂：

- 同一次回来购买只增加一个离线块；
- 多台工厂共享时间戳和离线块；
- 本段结束后购买的工厂不会追溯贡献到刚结束的离线段；
- 在线/离线混合发生在宏边界，单台宏始终保留。

最终输出前会完整重放一次，确保资源、价格、前置、时间戳和离线块一致。

## 预算与已知限制

- 当前 Beam 宽度为 32，宏深度为 24，单个分段贪心补全最多 16 个宏。
- 单个工厂暂保留“当前拥有 +1000 台”的规划域上限，不代表域外方案不存在。
- 搜索以确定性模拟次数预算为主，并以墙钟截止时间兜底；超时返回最近完整保底。
- 分段搜索只优化当前目标，不为后续目标提前投资，也不保证多目标全局最优。
- 目标选择仍沿用当前贪心规则；批量档位、Beam 宽度和时间预算都属于启发式限制。
- 计划版本升级为 33，旧版保存的计划会作废并重算。
